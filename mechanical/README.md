# 外壳交换模型

对外只保留：

| 文件 | 用途 |
| --- | --- |
| `front.stp` / `back.stp` | STEP 几何交换模型 |
| `front.3mf` / `back.3mf` | 3MF 打印 / 网格交换文件 |

**不发布 Creo 原生源文件**，包括 `.prt` / `.prt.*`、`.asm` / `.asm.*`、`.drw` / `.drw.*` 等，也不包含其修订历史。交换模型不提供完整参数化设计树，不应称为完整 Creo 设计源码。

打印 / 加工前应在自己的 CAD 或切片工具中检查单位、比例、壁厚、公差、装配干涉、材料与散热。文件存在不代表特定工艺或尺寸已经通过制造验收；不要把 3MF 内可能保存的工艺参数视为通用安全配置。
